# Future design briefs

These briefs came out of the July 2026 design workbench. They remain in the
repository because they contain systems, tests, and asset methods worth
revisiting. They do not report current implementation status.

Before building from one of these files:

1. Compare its assumptions with `main`.
2. Replace stale paths, hashes, and numeric allocations.
3. Move any implemented contract into `docs/specs/` or the relevant canonical
   document in the same change.

Current project truth lives in:

- `docs/CANONICAL_CONTEXT.md`
- `docs/CURRENT_PROJECT_STATE.md`
- `docs/VERIFICATION.md`

The retained briefs cover:

- ComPress account and entitlement integration
- agriculture, crop genetics, and the Bio-Engineer profession
- player-built grid structures and parcel geometry
- multiplayer failure scenarios
- the Network Engineer profession and player networks
- profession-stat and Commando direction
- realistic synthetic-player soaks
- repeatable weapon attachment authoring
- wardrobe materials and palette taxonomy

Completed lane notes, old proof logs, and one-off handoff files remain available
in Git history before commit `e9933ef2`; they are intentionally absent here.
