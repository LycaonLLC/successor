# Asset and code notes

This package is the standalone facial-texture work extracted from the Polygon Forge character-creator prototype. It contains project-authored compositor code and image-model-generated facial artwork produced during that project.

No body mesh, skeleton, animation, hair, clothing, MakeHuman asset, or Quaternius asset is included. The runtime has no bundled third-party dependency. The optional Three.js adapter expects the consuming project to provide its own Three.js build.

Use and redistribute the project-authored code and generated assets subject to the terms that govern the original project and its generated content. This file intentionally does not grant rights to unrelated product names or third-party characters.
